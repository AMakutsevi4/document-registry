# Document Workflow Service

Система управления документов с поддержкой пакетной и фоновой обработки.

## Технологический стек
*   Java 21, Spring Boot 3
*   PostgreSQL (Docker Compose)
*   Apache Kafka
*   Liquibase, JPA/Hibernate, MapStruct

---

## Архитектурные решения

### Обработка 5000+ ID в одном 
В базовой реализации используется @Scheduled для фоновой обработки документов пакетами, в соответствии с требованиями ТЗ.
Для обработки пакетов свыше 5000+ ID, лучше применить Apache Kafka. Основные преимущества:
- Мгновенный запуск;
- Оптимизация ресурсов;
- Надежность.

### Вынос Реестра утверждений в отдельную систему
Для отделения реестра в отдельный микросервис, я бы применил паттерн Transactional Outbox, а именно в сервисе документов смена статуса на APPROVED 
и запись в историю происходят в одной транзакции с сохранением события в специальную таблицу outbox в той же БД, и отдельным процессом пересылах их в Kafka,
 где сервис реестра слушает и сохраняет запись в свою БД.
